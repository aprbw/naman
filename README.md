## Overview

**NAMAN** is an AI Agent Skill designed to generate names for AI skills and tools that follow's Arian's personal preference.

## Execution Pipeline

The skill operates through a strict 6-phase pipeline to maximize quality and uniqueness:
1. **Semantic Seed Extraction**: Extract core concepts from input.
2. **Divergent Semantic Radiation**: Expand seeds into vast metaphors and synonyms.
3. **Generation Matrix**: Translate concepts into target lexicons iteratively.
4. **Algorithmic Grading & Pruning**: Apply strict Hard and Soft Gates.
5. **Taxonomic Clustering**: Group top candidates by typology.
6. **Payload Delivery**: Output polished results and a comprehensive audit trail.
